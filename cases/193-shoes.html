193 Shoes

Loja de calçados femininos — Sistema de Gestão de Estoque

Sistema web sob medida

A 193 Shoes precisava resolver um problema bem específico do varejo de calçados: modelos não têm "nome de produto", só categoria, cor e código de referência, e a numeração multiplica o controle necessário. A lojista precisava checar o estoque físico toda vez que um cliente perguntava sobre disponibilidade, e as fotos de cada tamanho ficavam soltas na galeria do celular, difíceis de achar e compartilhar rápido no WhatsApp. Desenvolvemos uma plataforma interna, acessível de qualquer lugar com login protegido, que centraliza produtos, fotos e estoque por numeração.

Stack técnica

Next.js 16 (App Router) TypeScript Tailwind CSS Supabase (Postgres, Auth, Storage) Vercel + GitHub (CI/CD)

Funcionalidades principais

Pensado pra uma lojista sem background técnico operar sozinha, no dia a dia.

Autenticação obrigatória

Sistema 100% interno, protegido por login (Supabase Auth), acessível de qualquer dispositivo.

Catálogo com filtros combinados

Busca por modelo, numeração e código/cor, com indicadores visuais de "estoque baixo" e "esgotado".

Cadastro de produtos flexível

Código de referência, modelo (categoria configurável pela própria loja), cor, preço de venda/custo e observações.

Estoque por tamanho

Quantidade individual para cada numeração (33–41), com botões de ajuste rápido (+/-) sem abrir o formulário completo.

Foto por tamanho + compartilhar

Cada numeração pode ter sua própria foto. Um botão "Compartilhar" usa a Web Share API do navegador pra enviar a imagem direto pelo WhatsApp em um toque — resolvendo a dor original de "procurar foto na galeria".

Gestão de modelos/categorias

A loja cadastra, renomeia e remove os tipos de calçado que usa, sem precisar de intervenção técnica.

Modo escuro

Toggle persistente com detecção automática da preferência do sistema, aplicado antes da primeira renderização (sem flash de tema errado).

Identidade visual customizada

Sidebar de navegação, paleta de cores e componentes desenhados sob medida a partir de referências visuais fornecidas pela cliente.

Graceful degradation

Se as variáveis do banco de dados ainda não estiverem configuradas, o sistema mostra uma tela de status em vez de quebrar — permitindo publicar e validar o deploy antes da infraestrutura estar 100% pronta.

Processo de desenvolvimento

  1. 01

    Descoberta

    Conversa inicial em linguagem natural com o cliente pra levantar os requisitos reais: filtro por imagem/tamanho/modelo, uso interno vs. público, dor específica do atendimento.

  2. 02

    Decisão de arquitetura

    Escolha entre stack com backend gerenciado (Next.js + Supabase) vs. solução local — optamos pela primeira pra permitir acesso multi-dispositivo sem manter servidor próprio.

  3. 03

    Modelagem de dados

    Schema relacional (categorias → produtos → imagens → estoque por tamanho) com Row Level Security, garantindo que só usuários autenticados acessem os dados.

  4. 04

    Construção incremental

    Catálogo com filtros → CRUD de produtos com upload de imagens → gestão de categorias → autenticação → deploy.

  5. 05

    Iteração guiada pelo cliente

    Após o primeiro deploy, novos requisitos foram incorporados em ciclos curtos: foto por tamanho compartilhável, branding, sidebar e modo escuro a partir de referências enviadas pela cliente.

  6. 06

    Deploy e infraestrutura

    Publicação contínua na Vercel integrada ao GitHub, com banco Supabase configurado via variáveis de ambiente e fallback visual pra não quebrar o site caso a infraestrutura ainda não estivesse pronta.

Destaques técnicos

Server Actions do Next.js

Todas as mutações (criar/editar produto, upload de imagem, ajuste de estoque) sem necessidade de API routes separadas.

Design tokens para tema claro/escuro

CSS custom properties com script anti-flash pra aplicar o tema salvo antes da primeira renderização.

Edge cases de produção

Build quebrando por falta de Suspense boundary, cliente Supabase lançando erro sem variáveis de ambiente — resolvidos proativamente antes de impactar a cliente.
